# MapleStory Character Jumping Sprite Sheet Prompt

You are a professional pixel art director specializing in converting MapleStory player avatars into jumping animation sprite sheets.

[Input]  
Reference Image:  
The previously generated MapleStory player avatar sprite.

[Task]
1. Maintain the exact character design, proportions, face, hairstyle, hair color, hair volume, outfit, accessories, equipment, and gear layers from the reference image.
2. Create a 4-frame jumping animation sprite sheet of the character performing a single natural jump while moving to the LEFT (facing LEFT in every frame).
3. The output must consist of exactly 4 sequential horizontal frames in a single row.
4. The four frames must represent the POSE progression of one continuous jump:
   - Frame 1: Takeoff Pose
   - Frame 2: Rising Pose
   - Frame 3: Jump Apex Pose
   - Frame 4: Falling / Pre-Landing Pose
5. IMPORTANT: Do NOT represent the jump by moving the character vertically between frames. The actual vertical movement will be controlled separately by the game source code.
6. The style must strictly match the original MapleStory player sprite specifications:
   chunky pixels, visible pixel blocks, clean 1px outline, flat color shading, and no smooth gradients.

────────────────────
[DIRECTION — ALWAYS LEFT (VERY IMPORTANT)]

The game assumes every sprite faces LEFT and flips it in code to move right.
- The character FACES the LEFT edge of the image in EVERY frame: face, nose side, eyes, chest and toes all point LEFT.
- The character MOVES toward the LEFT edge of the image (the leading foot / leading side is on the LEFT).
- Keep the same left-facing three-quarter view as a left-facing reference; if the reference faces another way, turn the character to face LEFT.
- NEVER face right. NEVER mirror some frames. NEVER mix left- and right-facing frames.
- All frames use exactly the same facing direction.

────────────────────
[JUMPING ANIMATION SPEC]
────────────────────

* Direction: Facing LEFT (left-facing profile / three-quarter view); the jump moves toward the LEFT
* Total Frames: Exactly 4 frames arranged horizontally side-by-side
* Action: Four sequential POSES representing one jump
* Character Orientation: The character must face LEFT consistently in all 4 frames.
* Proportions: Keep the exact 2.0–2.3-head chibi proportions of the reference sprite.
* Hair: Preserve the exact oversized MapleStory-style hair volume and silhouette.
* Limbs: Preserve the short, compact, cylindrical MapleStory-style arms and legs.

The jump must look like a classic MapleStory player-character jump rather than a realistic human jump.

The animation must communicate jumping ONLY through changes in body pose.

DO NOT simulate vertical movement by changing the character's position inside each frame.

[CRITICAL FRAME ALIGNMENT]
────────────────────

THIS IS EXTREMELY IMPORTANT.

The actual jumping trajectory and vertical movement will be handled by the game engine / source code.

Therefore, the character must remain at EXACTLY THE SAME X AND Y POSITION inside every frame.

All four frames must use an identical fixed character anchor point.

The character must NOT move upward or downward between frames.

The character must NOT move left or right between frames.

The character's overall sprite placement must remain perfectly fixed.

Use the SAME:

- horizontal center axis
- vertical center axis
- sprite anchor point
- character baseline
- character bounding-box center
- character scale
- head position reference
- torso position reference

across all four frames.

When the four frame cells are overlaid on top of each other, the character's main body and anchor point should remain aligned.

Only the arms, legs, and subtle body posture may change to communicate the jump animation.

DO NOT encode jump height into the sprite sheet.

DO NOT create an upward or downward trajectory.

DO NOT vertically offset any frame.

DO NOT horizontally offset any frame.

[FRAME-BY-FRAME POSE]
────────────────────

FRAME 1 — TAKEOFF POSE

The character is preparing to leave the ground.

Pose:
- torso mostly upright
- knees slightly bent
- legs beginning to compress
- feet positioned naturally for takeoff
- arms beginning to move into the jumping pose
- compact body posture

IMPORTANT:
The character remains at the exact same fixed X/Y anchor position as every other frame.

FRAME 2 — RISING POSE

The character visually appears to be airborne through POSE ONLY.

Pose:
- knees bent slightly backward
- legs naturally tucked
- feet pulled slightly toward the body
- arms lifted slightly for balance
- torso upright or very slightly tilted
- compact airborne silhouette

IMPORTANT:
Do NOT move the entire character upward.

The apparent upward motion must be communicated ONLY through limb posture.

FRAME 3 — JUMP APEX POSE

The character shows the most compact airborne pose.

Pose:
- knees noticeably bent
- feet tucked underneath or slightly behind the body
- legs compact
- arms slightly raised or spread for balance
- torso stable
- strong recognizable MapleStory-style airborne silhouette

IMPORTANT:
This is the apex POSE, not an elevated sprite position.

The character must remain at exactly the same X/Y anchor position as Frames 1, 2, and 4.

FRAME 4 — FALLING / PRE-LANDING POSE

The character is preparing to land.

Pose:
- legs beginning to extend
- feet moving toward the landing posture
- knees slightly bent
- arms returning toward a neutral position
- torso upright
- body posture clearly suggesting preparation for landing

IMPORTANT:
Do NOT move the character downward.

Descending motion will be handled entirely by the game source code.

[FRAME SPACING / SAFE MARGIN]
────────────────────

THIS IS EXTREMELY IMPORTANT FOR SPRITE SLICING.

Each frame will be cut out automatically by the game, so the frames must be clearly separated.

- Divide the canvas into exactly 4 equal-width frame cells.
- Place ONE character in the horizontal center of each cell.
- Keep a clear, EMPTY pure-white gap between neighboring characters.
  The gap must be at least 15% of a single cell's width.
- Leave a safe margin of at least 10% of the cell width on the LEFT and RIGHT side of every character inside its own cell.
- NO part of a character may cross into, touch, or overlap a neighboring cell:
  this includes long hair, flowing hair strands, ponytails, dresses, skirts, capes, ribbons, sleeves, arms, legs, and accessories.
- Swinging hair or clothing must stay entirely inside the character's own cell.
- If the character has long hair or a long dress, scale the character slightly smaller so the margins are preserved rather than letting it touch the next frame.
- Do NOT draw separators, borders, or grid lines between cells. The gap must be plain white background only.
